# Terrain3D — поляна и 4 тропинки

## Почему была «стена» из одного квадрата

Terrain3D хранит мир **квадратными регионами**. Старый вариант был 512×512 м: по краю региона высота оставалась большой, а снаружи — пусто, получался вертикальный обрыв как стена.

Сейчас: **один регион 256×256 м**, heightmap по центру в (0,0), **края карты прижаты к нулевой высоте** + мягкие «горы» за 20 м до границы.

## Раскладка «нарисована» кодом (v3)

При открытии сцены terrain **сам пересоздаётся**, если `layout_version` изменился (`regenerate_if_layout_outdated`).

- Поляна в центре, ровная трава  
- 4 тропинки-крест (земля/камень, texture 0)  
- 4 холма по диагоналям между тропинками  
- Мягкий подъём у края карты  

Вручную: **Editor Regenerate Now** на `WorldTerrain`.

## Схема мира

```
        [PathNorth]  (−Z)
              │
              │
[PathWest]───●───[PathEast]
         поляна
              │
        [PathSouth]  (+Z)
```

- **Поляна** (`meadow_radius_m`, ~24 м) — ровный центр, спавн.
- **Тропинки** — крест 5 м шириной, ~88 м от центра (настраивается).
- **Маркеры** `PathPortals/PathEast|West|North|South` — сюда ставить `LevelTransitionZone` для других миров.
- **Край** — холмы + невидимые стены (`WorldPlayBounds`).

## Как ограничивается мир

| Уровень | Что делает |
|--------|------------|
| Terrain | Один регион; за пределами нет mesh |
| Heightmap | Край обнуляется → нет обрыва в пустоту |
| `edge_blend_m` | Подъём рельефа у границы (~20 м) |
| `WorldPlayBounds` | StaticBody на слое world — игрок не уходит за квадрат |
| Порталы | `LevelTransitionZone` на концах тропинок → другие сцены |

Другие биомы — **отдельные сцены** (`cave_test.tscn` и т.д.), переход через зоны, а не бесконечный terrain.

## Настройка в инспекторе (`WorldTerrain`)

| Параметр | Смысл |
|----------|--------|
| `region_size_m` | Размер карты (256 = ±128 м от центра) |
| `meadow_radius_m` | Радиус поляны |
| `path_width_m` / `path_length_m` | Тропинки |
| `height_scale` | Высота холм (меньше = мягче) |
| `edge_blend_m` | Ширина «гор» у края |

Дальше — кисти Terrain3D: дорисовать тропинки, красить текстуры, траву.
